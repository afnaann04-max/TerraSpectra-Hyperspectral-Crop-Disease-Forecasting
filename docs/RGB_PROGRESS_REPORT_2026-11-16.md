## 3. Severity-label findings

The official dataset description reports six progressive disease severity levels and image-level severity annotation.

The described visual assessment criteria include:

- Lesion extent.
- Lesion height progression along the sheath.
- Symptom colour intensity.
- Lesion density and spatial spread.

The exact six class names or numerical codes, definitions and severity boundaries remain undisclosed.

The specific scoring scale used by this dataset has not been verified. The standard 0–9 rice sheath blight severity scale must not be assumed to apply.

## 4. Annotation findings

- Image-level severity annotation is reported in the official dataset description.
- The actual annotation file and its format have not been identified.
- The mapping between individual image files and severity labels has not been independently verified.
- Folder-based labels, segmentation masks and bounding-box annotations have not been confirmed.

## 5. Source evidence and limitations

The official Mendeley dataset description is the primary source for the reported six severity levels and visual assessment criteria.

A related ResearchGate publication was identified, but it has not been established as direct supporting documentation for this dataset's six-class annotation scheme.

The submitted investigation did not establish the exact class definitions, scoring boundaries or annotation structure.
